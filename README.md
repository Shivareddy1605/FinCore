
# FinCore

FinCore is an India-focused lending platform designed around transparent loan terms, traceable operations, and clear customer disclosures.

## Project Goals

- Provide a customer portal for loan applications and application status.
- Provide a finance operations dashboard for reviewing applications and managing loan workflows.
- Provide an audit console for inspecting offer versions, consent records, calculations, and operational events.
- Calculate loan amounts and repayment schedules using Java BigDecimal and explicit rounding rules.
- Keep accepted loan terms immutable and record subsequent changes as auditable events.
- Track repayment records, payment reconciliation, cancellations, and refunds.

## Initial Prototype

The initial version uses fictional data and simulated transactions.

It does not perform real KYC checks, credit bureau enquiries, loan disbursements, or payment processing.

## Planned Technology Stack

- Frontend: React and Vite
- Backend: Java and Spring Boot
- Database: PostgreSQL
- Version control: Git

## Development Principles

- Transparent calculations and disclosures
- Secure handling of sensitive data
- Role-based access control
- Auditable business events
- Automated testing and independent calculation checks
- Responsive and accessible user interfaces

## Important Note

This project is a software development prototype, not a live lending service or a determination of regulatory compliance. Legal and compliance requirements must be reviewed by qualified professionals before any real-world lending activity.
